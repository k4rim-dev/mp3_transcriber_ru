# mp3_transcriber_ru

Инструмент для локальной расшифровки русской речи из аудио и видео. Обрабатывает файлы по очереди и сохраняет результат в TXT рядом с исходником. Поддерживает таймкоды и разметку спикеров.

## Установка и запуск на Windows

1. Установить [Python 3.12 x64](https://www.python.org/downloads/release/python-31210/) с компонентом Tcl/Tk.
2. Запустить `setup.bat` для установки зависимостей.
3. Открыть `start.bat`.

Для ручной установки выполнить из папки проекта:

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

## Использование

1. Выбрать режим «Быстрее» или «Точнее» и при необходимости включить таймкоды и спикеров.
2. Перетащить файлы в окно или нажать «Добавить файлы». Настройки фиксируются при добавлении каждого файла в очередь.
3. Подтвердить загрузку, если нужных моделей ещё нет на диске.
4. Открыть результат двойным щелчком по готовой строке. Например, для `запись.mp4` получится `запись.txt` в UTF-8. Если такой TXT уже существует, новый файл получит имя `запись (2).txt`.

Чтобы прервать обработку, нажать «Отменить файл». Текущая строка получит статус «Отменено», TXT для неё не сохранится, а очередь перейдёт к следующему файлу.

Поддерживаются MP3, M4A, WAV, OGG, OPUS, FLAC и MP4. В MP4 используется первая аудиодорожка. Для ролика с YouTube нужен файл, сохранённый на диске.

Таймкоды отмечают начало фрагмента в формате `[00:12:34]`. Спикеры нумеруются заново в каждом файле. На шуме и при одновременной речи разметка может ошибаться.

## Модели и место на диске

| Настройка | Модель | Размер на диске |
| --- | --- | ---: |
| Быстрее (по умолчанию) | Whisper `base` | ~148 МБ |
| Точнее | Whisper `small` | ~486 МБ |
| Спикеры | Pyannote, сегментация речи | ~6 МБ |
| Спикеры | 3D-Speaker, различение голосов | ~40 МБ |

Перед первой загрузкой окно показывает размеры отсутствующих моделей и папку установки. Новые веса сохраняются в `models/`. Уже скачанные модели Whisper также можно использовать из локального кэша Hugging Face.

Интернет нужен для установки зависимостей и загрузки моделей. Дальнейшая обработка идёт офлайн, на CPU. Длительность зависит от записи, процессора и выбранного режима. Разметка спикеров выполняется отдельным проходом.

Распознавание использует [faster-whisper](https://github.com/SYSTRAN/faster-whisper), чтение аудио выполняет PyAV со встроенными библиотеками FFmpeg, разметку спикеров выполняет [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx).

## Структура проекта

| Файл или папка | Назначение |
| --- | --- |
| `app.py` | Окно, перетаскивание файлов, очередь, прогресс и отмена. |
| `transcriber.py` | Загрузка моделей, чтение аудио, распознавание, разметка спикеров и сохранение TXT. |
| `README.md` | Описание, установка и использование. |
| `requirements.txt` | Python-зависимости проекта. |
| `setup.bat` | Создание окружения и установка зависимостей на Windows. |
| `start.bat` | Запуск окна из локального окружения. |
| `.gitignore` | Правила исключения локальных данных из Git. |
| `.venv/` | Локальное окружение и установленные пакеты. Создаётся при установке. |
| `models/whisper/` | Веса Whisper, скачанные транскриптором. |
| `models/speakers/` | Веса двух моделей разметки спикеров. |
| `__pycache__/` | Служебный кэш Python, который создаётся при запуске. |
